# 分组启动台 / Grouped launcher

一个 FullWidget 桌面组件：把程序、文件夹和网址收进分组的标签页里，一次只显示当前分组。直接用宿主内置接口，不需要安装插件。

- 分组标签页：切换标签只看这一组的入口；每个分组可以各自用图标网格或紧凑列表。
- 拖拽即用：拖动入口调整顺序，拖到别的标签就移进那个分组；也可以把文件和 HTTP/HTTPS 链接直接拖进组件。
- 编辑模式：右上角「编辑」打开工具栏，可以添加程序 / 文件 / 文件夹 / 网址，管理分组（改名、前移后移、删除）。
- 键盘：单击选中，双击或 Enter 打开，上下方向键换一个；焦点在入口区时 Delete / Backspace 移除入口（不删文件），6 秒内可撤销。
- 单层或多层标签：在组件内容设置里开启「多层分组标签」，标签溢出时自动向下换行；关闭时单层横向滚动，也支持滚轮。

## 权限

- `shell.launch`：打开入口指向的程序或文件夹，以及用文件夹选择器挑路径。
- `shell.open`：在默认浏览器里打开网址入口。

不需要其他权限，不联网，不含任何远程脚本。

## 数据

每个桌面实例用 `widget.storage` 的 `board` 键保存全部数据：最多 50 个分组、200 个入口。保存是串行的，失败时页面里的操作会保留，可以点「重试保存」；读取失败不会覆盖已有存档。

首次使用时只会预设一个「文件资源管理器」入口，其余自己添加。

## 文件

- `index.html` — 结构
- `style.css` — 跟随宿主三套主题的样式
- `model.js` — 数据校验与操作
- `main.js` — 宿主接口、交互、渲染与保存
- `icon.svg` — 图标
- `preview.png` — 预览图
