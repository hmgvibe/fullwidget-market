# 我的课表

课程以中国标准时间（UTC+8）显示和提醒。组件不联网，权限仅为 `notify`。

## 导入课表

点击「下节课」旁边的齿轮 →「更换课表…」。首次使用可直接点「导入课表」。每次只保留一份课表，成功后立即更新提醒，失败保留旧课表。导入结果保存在当前卡片的 `widget.storage`，重载后继续使用；删除卡片时一并删除，不会和其他卡片共享。

| 文件 | 支持范围 |
| --- | --- |
| 时光课程表 `.json` | 包含 `courses`、`timeSlots`、`config` 的导出，按教学周、节次和自定义时间展开；开学日为周一。 |
| WakeUp `.wakeup_schedule` | 「导出为备份（可导入）文件」生成的五行文本备份；读取开学日、节次、单双周，按周一显示。 |
| 日历 `.ics` | 读取有具体时间的事件、重复日程和调课例外；跳过全天事件。未带时区的时间按中国标准时间处理；其他时区须有日历内的时区定义，UTC 可直接读取。无限重复事件展开到未来一年（起始时间晚于今天时，从起始日起算）。 |
| `.xlsx`、`.xls`、`.csv`、`.tsv` | 逐行课表，Excel 读取第一张工作表；CSV/TSV 支持 UTF-8 和 GB18030。 |

表头必填：`日期,开始时间,结束时间,课程名`；可选：`教室,老师,备注`。每行是一节实际开课记录，日期用 `yyyy-mm-dd`，时间用 `HH:mm`。示例见 `timetable-template.csv`。学校的横排周课表、合并单元格、PDF 和截图需要先整理或转换。

文件最大 2 MB，最多 5,000 个上课时段。内置解析库原样分发，许可证见 `vendor`：

- [ICAL.js 2.2.1 源码](https://github.com/kewisch/ical.js/tree/v2.2.1)（MPL-2.0）
- [SheetJS CE 0.20.3 分发包](https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz)（Apache-2.0）
- [Papa Parse 5.7.1 源码](https://github.com/mholt/PapaParse/tree/5.7.1)（MIT）

## 显示与提醒

- 压低卡片时只显示「下节课」；拉高时展开周历。默认宽度可同时看两天，拉宽时从选中的日期向右增加日期列。多列显示上课时间，悬停时间可看完整时段。
- 左右箭头切换教学周，点日期调整第一列，点回转箭头回到今天。浏览其他日期时，顶部的实时提醒保持独立。
- 在 FullWidget 控制中心的「我的组件」选择「我的课表」，可修改提醒分钟数、关闭通知或打开自动铃声。默认提前 10 分钟发通知，自动铃声默认关闭。
- 同一设置页可打开「24 小时制」，默认用带上午、下午的 12 小时制。卡片和通知用同一种格式；时间计算始终以中国标准时间为准。
- 「下节课」旁的齿轮菜单可试听、更换铃声或恢复默认三音提示。铃声支持 1 MB 以内的 MP3、WAV 或 OGG，本地保存。
- Windows 通知由 FullWidget 主程序调度。铃声由卡片播放，可能受全屏暂停、自动播放策略、睡眠和静音影响；启动后可点一次「试听」。FullWidget 退出时不可提醒。
- 组件不附带预设课表，预览使用虚构课程。FullWidget 内移除卡片即可取消这张卡片的后续提醒。
